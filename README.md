# コンサータ服薬ログ（オフラインWebアプリ）

## 公開URL
https://wassanborn72.github.io/concerta-log/

## 機能
- 日付ごとの服薬量・服薬時刻・睡眠・主観的変化・副作用・作業実績の記録
- 7日間・30日間の推移グラフ（最大2項目の比較）
- 日付ごとの記録の編集・履歴表示
- CSVの書き出し・読み込み
- localStorageによる端末内保存
- Service Workerによるオフラインキャッシュ
- Androidホーム画面への追加（PWA）

## 利用方法
1. HTTPSの公開URLをAndroid Chromeで開き、オンラインで一度読み込みます。
2. Chromeメニューから「アプリをインストール」または「ホーム画面に追加」を選びます。
3. 以降はキャッシュされたアプリをオフラインでも起動できます。

## データと注意
- 記録はブラウザーのlocalStorageに保存され、外部サーバーへ送信する処理はありません。
- ブラウザーデータの消去、ブラウザー/アプリの削除、端末故障などで記録が失われる場合があります。定期的にCSVを書き出してください。
- CSVには服薬や体調に関する個人情報が含まれます。共有先・保存先に注意してください。
- 数値は個人の経過観察用で、診断尺度や薬の効果判定ではありません。服用方法・用量は処方に従ってください。
